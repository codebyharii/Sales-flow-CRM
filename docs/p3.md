# Phase 3: Landing Page UI & Single Hero CTA — Execution Blueprint

> **PRD Priority:** MUST (REQ-01, Screen 01 Wireframe)  
> **Phase Goal:** Build a clean, trustworthy marketing landing page adhering strictly to PRD Screen 01 layout rules: logo-only navbar, single primary high-contrast CTA button ("Book Appointment"), decorative trust markers, and custom design tokens.

---

## 1. Scope & PRD Screen 01 Constraints

### Strict Design Guidelines (PRD Section 05 - Screen 01)
1. **Logo-Only Navigation:** Header displays the brand logo ONLY. **No competing nav links or secondary login buttons** in the header.
2. **Single Hero CTA:** High-contrast primary CTA button labeled **"Book Appointment"** (`var(--primary)` `#1e9df1`). Nothing competes with it visually.
3. **Modal Overlay Binding:** Clicking "Book Appointment" opens the Auth Modal as an overlay without navigating away.
4. **Supporting Trust Cards:** Below-the-fold 3-column feature grid (e.g., "1-on-1 Consultation", "Instant Scheduling", "Tailored Solutions").
5. **Typography & Styling:** Google Sans Flex for titles (`font-sans`), Inter for body text, IBM Plex Mono (`font-mono`) for eyebrow badges.
