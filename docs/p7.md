## 2. Step-by-Step Deployment Guide

### Step 1: Set Up Production Database (Neon PostgreSQL)
1. Log in to [Neon Console](https://console.neon.tech).
2. Create a new project named `sales-booking-flow`.
3. Copy the pooled connection string (`DATABASE_URL`) and direct connection string (`DIRECT_URL`).

### Step 2: Push Repository to GitHub
```bash
git init
git add .
git commit -m "feat: complete Book a Sales Meeting application (Phase 0 - 6)"
git branch -M main
git remote add origin https://github.com/your-username/sales-booking-flow.git
git push -u origin main
```

### Step 3: Connect Vercel Project
1. Import repository in [Vercel Dashboard](https://vercel.com/new).
2. Configure environment variables in Vercel settings:
   - `DATABASE_URL`: Production Neon pooled PostgreSQL URL
   - `DIRECT_URL`: Production Neon direct PostgreSQL URL
   - `NEXTAUTH_SECRET`: Generate via `openssl rand -base64 32`
   - `NEXTAUTH_URL`: `https://your-app-name.vercel.app`

### Step 4: Run Production Migration
```bash
npx prisma migrate deploy
```

## 3. Live Smoke Testing Checklist

1. **Landing Page Load:** Visit live Vercel URL → verify instant render of hero section and single "Book Appointment" CTA button.
2. **User Registration:** Click CTA → submit registration form → verify HTTP 201 response and automatic redirect to `/booking`.
3. **Protected Route:** Open `/booking` in incognito browser → verify instant Edge redirect to `/?login=1`.
4. **Calendar Embed:** Log in on `/booking` → verify Cal.com widget embeds and renders availability slots.
